# 🎨 Desafio Flexbox - Cards Horizontais

Este projeto foi desenvolvido como parte de um desafio prático de CSS Flexbox. O objetivo foi transformar cards verticais em uma lista de postagens horizontais com estilo neon e cores vivas.

## 🚀 Alterações Realizadas

- **Direção do Flexbox (`article`):** Alterado de `column` para `row`, alinhando imagem, título e texto em linha.
- **Largura dos Cards:** Configurada a propriedade `flex: 1 1 100%` para que cada card ocupe a largura total do contêiner.
- **Alinhamento Customizado (`align-self`):**
  - A propriedade `align-self: flex-start` foi aplicada na imagem do card.
  - A propriedade `align-self: flex-end` foi aplicada ao botão de ação dentro do card para quebrar o alinhamento padrão dos demais elementos.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3 (Flexbox & Variáveis)**
- **JavaScript**
